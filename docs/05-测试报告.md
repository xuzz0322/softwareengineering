## 6. 中文乱码回归修复

用户截图发现数据库动态文本乱码，而静态中文正常。根因是初始化 SQL 未指定连接编码，UTF-8 字节被按 Latin-1 导入。两个初始化文件现显式执行 SET NAMES utf8mb4。现有数据库先备份，再使用 scripts/repair-seed-encoding.sql 精确匹配错误的种子文本并修复，不删除选课、成绩或账号。重启应用刷新课程目录缓存。

新增集成断言核对课程名、学院、教室、学生姓名和学期名的精确中文；全新数据库上 61 项检查通过。本机 8080 接口也已核对十个教学班的中文字段正确。
