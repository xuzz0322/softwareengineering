# 课程设计文档清单与填写说明

项目：校园选课系统。技术：C++17、HTML/CSS/JavaScript、MySQL 8.4。团队按四人安排，以四位成员姓名标明岗位，常鹂沣 为组长；开发计划采用六周相对周期。

## 3. 阅读与归档

先阅读需求分析和设计文档，再按 README 启动项目。测试计划说明如何验证，测试报告记录已经验证的结果；四份岗位总结说明各模块的技术方案及问题分析，组长报告汇总全组范围和遗留工作。

文档已使用四位成员姓名；学号、个人工时及签名未填写。实际贡献率应依据工作记录认定。

## 4. 当前验收状态

自动化集成 82 项检查通过，C++ 规则 12 项断言通过。浏览器视觉、完整点击流程、原题生产级并发及真实外部系统联调尚未验收。没有完成的检查应保留为未完成，不补填为通过。

文档中的设计图为 Mermaid 源码，可在支持 Mermaid 的 Markdown 编辑器中预览。若课程另有封面、Word/PDF 格式或排版要求，应按教师提供的模板另行排版。
